## 🛠️ Configuration Recommandée TiviMate & Fire TV Stick

Pour contrer le bridage opérateur (Free, Orange, SFR, Bouygues, Proximus, Swisscom), il suffit d’utiliser un DNS alternatif chiffré et un routeur sécurisé. Le DNS over HTTPS (DoH) ou DNS over TLS (DoT) masque les requêtes DNS, empêchant l’opérateur d’identifier les flux vidéo et de les limiter. Un routeur compatible OpenWrt ou pfSense permet d’instaurer des règles de firewall, de forcer le routage via le VPN intégré et d’activer le NAT 6 pour contourner les filtres IPv4. En combinant un serveur DNS privé (Cloudflare 1.1.1.1 / 9.9.9.9) avec un tunnel WireGuard, le trafic reste encrypté du domicile jusqu’au point d’échange, garantissant une bande passante stable et une latence réduite, même pendant les pics d’utilisation. Ainsi, votre expérience streaming reste fluide, sans coupures ni dégradations visibles.

### Paramètres Essentiels pour un Streaming Sans Freeze (FR / BE / CH) :
- **Décodeur Vidéo** : Privilégier le décodage matériel 'Hardware (HW+)' dans TiviMate pour décharger le processeur du Fire TV Stick.
- **Taille du Buffer** : Configurer la mémoire tampon sur 'Moyen' ou 'Grand' (3 à 5 secondes) pour absorber les micro-variations de bande passante.
- **Adaptation Fréquence (AFR)** : Activer l'Auto Frame Rate matching pour synchroniser l'affichage de votre téléviseur avec le flux 50 fps européen.
- **Connexion Réseau** : Privilégier un adaptateur Ethernet USB pour éliminer les interférences Wi-Fi 5 GHz.
